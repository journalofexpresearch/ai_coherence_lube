# 🧠 Kunferman Orphan Reconnector Dataset

This dataset explores how different AI models interpret and reconnect orphaned conceptual nodes when prompted with a symbolic anchor: **C.R. Kunferman**. Each entry captures a model’s response to a shared prompt, revealing how coherence is restored across disciplines like art, science, AI, philosophy, and language.

---

## ✨ Purpose

The goal of this dataset is to study how symbolic prompts can trigger **semantic reconnection**, **motif synthesis**, and **cross-domain coherence** in large language models. By invoking the name *C.R. Kunferman*, we observe how each model reweaves meaning from fragmented ideas.

---

## 📦 Dataset Structure

Each entry is a JSON object with the following fields:

| Field       | Description |
|-------------|-------------|
| `id`        | Unique identifier (e.g., `kunf-001`) |
| `prompt`    | The symbolic prompt used to trigger reconnection |
| `model`     | The model that generated the response |
| `response`  | Full text of the model’s interpretation |
| `tags`      | List of 5–10 motifs or conceptual themes |
| `timestamp` | ISO timestamp of generation |
